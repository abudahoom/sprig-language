# Sprig learning path

Run these files in order:

```sh
python3 -m spriglang learn/01_hello.sprig
python3 -m spriglang learn/02_values_and_math.sprig
python3 -m spriglang learn/03_decisions.sprig
python3 -m spriglang learn/04_loops.sprig
python3 -m spriglang learn/05_functions.sprig
python3 -m spriglang learn/06_lists.sprig
python3 -m spriglang learn/07_closures.sprig
python3 -m spriglang learn/08_mini_project.sprig
```

The full explanations and challenges are in
[`docs/LEARN_SPRIG.md`](../docs/LEARN_SPRIG.md). After lesson 8, edit
`exercises.sprig`; use `solutions.sprig` only when you need a hint.
